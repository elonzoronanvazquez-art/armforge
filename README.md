# ARMFORGE

> Forge the arms. Break the world.

ARMFORGE is an original Roblox arm-based destruction simulator. You punch rocks that **visibly break apart piece by
piece**, earn coins and XP, upgrade and collect extraordinary arm sets, train, learn skills, rebirth and sail to new
islands. The arms are the game: they are the character's visual identity, the combat system, the collection and the
progression.

The first-time loop: spawn at the Great Forge, follow the glowing path to the Starter Field, punch a rock, watch its shell
chip away to its glowing heart, and fight the creature that bursts out. Collect the rewards, upgrade your fists, learn skills,
and keep going: every island ends with a guardian that, together with a rebirth, opens the way to the next one.

## Quick start (Windows)

Requirements already used by this repo: Rojo 7.7, Lune 0.11, luau-lsp, Roblox Studio with the Studio MCP server, Python 3.

```bash
# build a place file and open it in Studio
rojo build default.project.json -o build/armforge.rbxl

# tests (356: pure logic, a creature fight simulation and the real server services on a fake Roblox server, under Lune) and strict typecheck (both Luau solvers)
lune run tests/run
powershell -ExecutionPolicy Bypass -File scripts/typecheck.ps1     # or: bash scripts/tc.sh

# fast loop against an OPEN Studio (no Rojo plugin needed): sync scripts, restart play, show filtered output
bash scripts/reload.sh
```

The place file contains scripts only. **The world is generated by code at server start** (terrain, islands, landmarks,
rocks), so press Play to see it. Studio's DataStore is unavailable for unpublished places, so the game falls back to an
in-memory store there and says so in the output.

### Controls

| Input | Action |
|---|---|
| Click / tap PUNCH / gamepad R2 (hold) | Punch the rock in front of you |
| 1 2 3 4 / tap skill slots | Charged Smash, Critical Focus, Overdrive, Shatter Wave |
| F  K  B  M  R  O | Arms, Skills & Training, Boosters, Islands, Rebirth, Menu |
| E (prompts) | Use the Armory console, training stations, Skyport and Reforge Core |

## What is in the game

* **9 rock types on 3 islands**, built from layered chunks that are stripped around each impact (see ARCHITECTURE).
* **6 arm sets** (Starter Fists, Stonebreaker, Alloy, Crystal, Magma, Void) with different cooldowns, crit, armor
  pierce, traits, attack animations and visuals; one set is equipped at a time and equipping REPLACES it.
* **Procedural attack animation** (no uploaded animations): keyframed poses with anticipation, contact, follow-through,
  weight transfer, trails, hit-stop and camera shake proportional to the strike.
* **Training Yard** with four server-timed mini-games, **4 skills**, **5 booster types**, XP/levels, **Rebirth**, and
  **islands gated by level and rebirth**.
* **Cosmetics** (palette, finish, trail, glow) owned separately from stats.
* Server-authoritative everything, versioned save schema with session locking (DataStore path unverified: see
  VERIFICATION), rate limiting and validation on every remote.
